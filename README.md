En este proyecto se le aplica un refactor completo usando el patrón de diseño Abstract Factory, desacoplando la lógica de la capa visual para que las entidades del juego ya no dependan de gráficos específicos. Para verificar que funciona, solo se debe ir al método init() dentro de Game.java, descomentar la fábrica que se quiera probar (SpriteGameFactory, VectorGameFactory o ColorfulVectorGameFactory) y correr el archivo con Shift + F6 en netbeans o ejecutando mvn exec:java -Dexec.mainClass="com.balitechy.spacewar.main.Game" en la terminal, lo que cambiará al instante toda la estética del juego sin alterar su funcionamiento.
